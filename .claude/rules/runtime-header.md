# The C runtime header and bootstrap/c

The C of `bootstrap/c` builds with no ATS2 installed (bats#283): `--to-c` writes `_bats_native_runtime.h`, a header for the ATS2 C runtime macros and prelude functions the generated C uses (the same text as the wasm build's, `put_runtime_macros` in `src/build.bats`, over libc, plus the print and exit functions), and empty stubs for the three `libats/libc/CATS` files the C names (`_bats_native_stubs`), and the Makefile compiles with `-D_ATS_CCOMP_HEADER_NONE_ -D_ATS_CCOMP_EXCEPTION_NONE_ -D_ATS_CCOMP_PRELUDE_NONE_ -D_ATS_CCOMP_RUNTIME_NONE_ -include _bats_native_runtime.h -I_bats_native_stubs`, as the wasm build does, with no warning flags turned off. PATSHOME is for running patsopt only; the compiler a normal `bats build` makes still compiles with ATS2's headers.

**The runtime header (its method).** ATS2's own headers (`ccomp/runtime/*.h`, `prelude/CATS/*.cats`) are GPL-3.0-or-later and are not copied into the tree: the repository declares no licence, and copying would carry GPL-3 into it. The header is written here, from the use sites in the C that patsopt emits (the names and shapes in `bootstrap/c`, and in the wasm fixtures' C) and from the semantics ATS2 documents for each name, with its own parameter names, its own bodies and its own structure. The names are ATS2's, since they are the interface the emitted C is written against. Where ATS2 has a macro, this has a macro with another body where the interface leaves one to choose; the arithmetic, comparison and conversion functions of the prelude are typed `static inline` functions made by two helper macros (`BATS_FN1`, `BATS_FN2`), not a copy of ATS2's macros. What each must do: a name that ends a type says which C type it is; `ATSCKpat_con0` is true for the small integer that stands for a constructor without fields, `ATSCKpat_con1` for a pointer (1024 or above, below which are the small integers) whose first word is the tag; `ATSINSmove_con1_new` and `ATSINSfreecon` allocate and free a constructor block with the C library's malloc and free; `ATSfunclo_clo` calls the code address a closure begins with (`cfun`); `ATSINStmp*`, `ATSINSmove_*` and `ATSINSstore_*` are assignments of the shapes their names give; `ATStailcal_beg/end` and `ATScaseof_beg/end` open and close a `do { } while (0)` that `break` leaves (a branch ends in `break`); the `ATSdynload*` macros declare, set and call a module's load flag. How it is tested: the fixpoint (a compiler built from `bootstrap/c` with this header regenerates `bootstrap/c` byte for byte), the whole fixture suite run by that compiler, the wasm fixtures (`tests/build-wasm`, `tests/test-wasm`, which compile with the same text), and gcc compiling every module with no warning flags turned off. `ATS_MALLOC` in the native header exits with a message when malloc answers NULL; the wasm runtime's own malloc is used as it is. The macros of ATS2 that no emitted C names are not defined; the wasm build has always carried the macros wasm consumers (quire's C is not in this repository) might use, so that set is kept, every one written afresh, and a macro found unused by all consumers is a candidate to remove. Copying check (the `#define`s of the generated `_bats_native_runtime.h`, compared with those of ATS2's `ccomp/runtime/*.h`, `prelude/CATS/*.cats` and `libats/libc/CATS`, whitespace ignored, by a script that reads both): 133 defines here, 124 with an ATS2 name; **23 have the same parameters and body**, 40 more agree only up to the names of the parameters, and 61 differ. The residue is the one-line macros whose expansion the interface forces. The 23 are empty or a constant or a keyword or a name: `atsbool_true` and `atsbool_false`, `ATSextern`, `ATSstatic`, `ATSstruct`, `ATSelse`, `ATSbranch_end` (`break;`), `atspre_strlen`, `ATSPMVbool_true/false`, `ATStyclo` (`struct { void *cfun; }`, the field name is the emitted C's), and the empty markers (`ATSdynload`, `ATSbranch_beg`, `ATSextcode_beg/end`, `ATSfunbody_beg/end`, `ATSthen`, `ATSPMVempty`, `ATSINSmove_con1_beg/end`, `ATSINSmove_fltrec_beg/end`). The 40 are one token, a one-token wrapper or a declaration or statement form that has one spelling: the type wrappers (`atstkind_type(kind)` is `kind`), `ATSINSgoto(t)` is `goto t`, `ATSif(t)` is `if (t)`, `ATSreturn(r)` is `return (r)`, `ATStmpdec(n, t)` is `t n`, `ATSstatmpdec(n, t)` is `static t n`, `ATSPMVptrof(p)` is `(&(p))`, `ATSSELfltrec(r, t, f)` is `((r).f)`, `ATSmainats_0_void(e)` is `mainats_0_void()`, the literal wrappers (`(literal)`), `ATSINSmove_void(d, c)` and `ATSINSpmove_void` (`c`, which may be empty), and the empty ones with a parameter. Where another correct formulation exists the macro uses it (a cast spelt once in `BATS_CAST`, `for (;;) { ... break; }` for `do { } while (0)`, a subscript for a dereference, `->` as `.` of a dereference, a tentative definition for an initialised flag, the prelude as typed functions), and the typedefs, the macros and the prelude are ordered by this header's own scheme (alphabetical, grouped by what they do in the emitted C). Whether this residue is acceptable is the owner's decision.

The generated Makefile (`bootstrap/c`, `--to-c`) has `make install`, which puts the compiler at `$(PREFIX)/bin/bats` (`PREFIX` defaults to `~/.bats`).
